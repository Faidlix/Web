UNITY / RUNTIME & EDITOR TOOLS

FDX Attachment Motion

角色配件掛載、次級動態與柔性骨架權重工具。

v1.0.0已驗證 Unity 6000.3.13f1MIT

讓配件跟隨角色，自然產生動態。

支援 FBX、GLB、Prefab 與一般 Unity 物件；自動複製 Mesh，不直接修改原始匯入資產。

  • 角色配件
  • Secondary Motion
  • 骨架與權重
  • Runtime / Editor
FDX_AttachmentManager
掛在 Animator 角色，以 Humanoid 骨頭或任意 Transform 掛載 Prefab／場景物件；統一套用或逐項設定配件內的 Secondary Motion。
FDX_SecondaryMotion
支援現有骨架，無骨架物件可自動建立單一旋轉軸心；提供慣性、彈力、阻尼、旋轉上限、重力、風力、碰撞、持續外力與 AddImpulse。單一軸心可連接多個尾端，使用圓柱偵測範圍。
FDX_RigWeightEditor
建立柔性骨架、自動計算網格權重，以筆刷增加、減少、取代、平滑與正規化權重。
